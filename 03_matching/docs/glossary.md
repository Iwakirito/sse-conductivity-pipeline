# Glossary

ICSD
- Inorganic Crystal Structure Database identifier; cross-database linkage used as strongest signal.

MPID
- Materials Project identifier (`mp-xxxxx`).

Reduced Formula
- Canonical composition representation with integer stoichiometry and reduced ratios (from `pymatgen.Composition`).

Space Group (SG)
- Crystallographic symmetry category; compared by number or normalized symbol.

Crystal System
- One of: triclinic, monoclinic, orthorhombic, tetragonal, trigonal, hexagonal, cubic.

Deprecated (MP)
- A document marked as superseded or not preferred; kept for provenance.

StructureMatcher
- Pymatgen tool that compares structures for geometric equivalence with tolerances.

SpacegroupAnalyzer
- Pymatgen tool to infer space group and symmetry from a structure.

Chemsys
- Element set descriptor (e.g., `Li-O-Bi`) used in MP searches to broaden candidate retrieval.
