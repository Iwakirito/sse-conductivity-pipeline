# 04_analysis — statistics & figures

`make_figures.py` regenerates, from `../data/final/sse_conductivity_master.csv`, the manuscript
figures that aggregate over the whole dataset:

| file | content |
|---|---|
| `figures/DefFig1.png` | entries per source; entries per tier; tier composition within each source |
| `figures/DefFig2.png` | structural-family assignment per source and overall |
| `figures/DefFigCov1.png`, `DefFigCov2.png` | experimental entries per MP-ID (full range and 1–21 zoom) |
| `figures/Fig7_Bar_Element_Top20.png` | twenty most frequent elements (counted once per entry) |

Every number printed on those figures is also written to `figures/figure_values.json`, so the
manuscript text can be checked against the figures mechanically.

```bash
python make_figures.py --master ../data/final/sse_conductivity_master.csv --out figures/
```

The remaining figures in `figures/` were produced in Microsoft Excel. `Fig2b_PieChart_Family.png`
(assigned families only), `Fig5a/5b/5c` (temperature panels) and the two schematics (`datacleaning.png`,
`hierarch.png`) are unaffected by the 17-entry exclusion described in `../CHANGELOG.md` (the excluded
entries carry no family label and no temperature) and are therefore identical for the published table.
`Fig3_Histogram_LogConductivity.png`, `Fig4a_Ridgeline_Conductivity_Tier.png` and
`Fig4b_Ridgeline_Conductivity_Family.png` were rendered from the pre-exclusion 3123-row table; the 17
excluded entries (all Tier 4, all from Shon et al. 2023) represent 0.5 % of the rows and do not change
these distributions at the resolution of the plots. Because the dataset is openly published, each of
them can be regenerated by any reader directly from `../data/final/`.
